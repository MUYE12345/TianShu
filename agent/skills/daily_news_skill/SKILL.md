# 每日新闻

从四个中文AI/科技媒体抓取、聚合和摘要每日科技新闻。

## 何时使用

- 用户问"今天的新闻"、"有什么AI新闻"、"科技新闻"
- 用户想追赶科技/AI最新动态
- 用户提到以上四个来源名字中的任何一个

## 工作流程

1. **抓取新闻** — 使用新闻聚合器爬取全部四个来源（或用户指定的单个来源）
2. **AI摘要** — 生成全面的中文摘要，覆盖所有来源的要点
3. **跨源合并** — 同一话题被多个来源报道时，合成统一文章
4. **呈现结果** — 显示来源、标题、AI摘要和原文链接

## 来源

| 标识符 | 名称 | 特色 |
|--------|------|------|
| deep_tech | 深科技 | 深度科技分析 |
| machine_heart | 机器之心 | AI行业动态 |
| qbitai | 量子位 | AI/科技快讯 |
| aiera | 新智元 | AI前沿资讯 |

## 输出格式

```
📰 今日AI摘要
[AI生成的多段落总结]

🔬 深科技(N篇)
- [标题](URL) — 一句话摘要

🧠 机器之心(N篇)
...
```

## 关联技能

- `current-news` — 时事新闻（新京报）
- `wiki-creator` — 将重要新闻保存为知识页面
