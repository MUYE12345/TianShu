# Wiki创建器

创建和组织知识的技能，支持知识图谱自动构建。

## 何时使用

- 用户要求创建、阅读、更新、删除Wiki页面
- 用户提到"记笔记"、"wiki"、"知识管理"、"概念"
- 用户使用 `[[wikilink]]` 语法连接想法
- 用户想看知识图谱、需要文档化学习内容

## 工作流程

### 创建页面

1. 询问用户**页面标题**
2. 帮助确定**页面类型**（从15种中选择）
3. 询问可选**标签**（逗号分隔的关键词）
4. 用Markdown编写内容，使用 `[[wikilink]]` 语法链接其他页面
5. 通过Wiki API保存

### 阅读页面

1. 通过slug/标题加载页面
2. 显示内容、渲染的wikilinks
3. 显示反向链接（引用此页面的其他页面）

### 知识图谱

1. 页面创建/更新时，图谱自动更新
2. 每种页面类型在图中有不同颜色
3. 节点是页面，边是wikilink引用

## 页面类型（参考 `references/page_types.md`）

## 示例

**输入**: "记一个关于AI的概念"
**输出**: 创建页面 type=concept, title="人工智能", tags=["AI","机器学习"], 用Markdown写内容

**输入**: "把这则新闻和之前的AI概念关联"
**输出**: 创建新闻页面, 加入 `[[人工智能]]` wikilink → 图谱自动生成边
