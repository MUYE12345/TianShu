# 时事新闻

从新京报抓取、聚合和摘要时事新闻。

## 何时使用

- 用户询问时事或要闻（"今天有什么新闻"）
- 用户提到"时事"、"要闻"、"今日热点"
- 用户想了解政治、国际或科技政策新闻
- 用户询问"新京报"或"北京新闻"

## 工作流程

1. **默认显示第一热点** — 首页展示"第一看点"板块
2. **切换板块** — 用户可在四个板块间切换：第一看点/国际/科技/政事
3. **AI摘要** — 每个板块顶部有AI生成的要点摘要
4. **文章列表** — 每篇文章显示标题（点击跳转原文）+ 时间戳 + 摘要
