# 论文解析器

上传、解析、理解学术论文的技能，使用OCR和AI分析。

## 何时使用

- 用户上传学术论文PDF
- 用户要求"分析这篇论文"
- 用户在arXiv上搜索论文
- 用户需要论文翻译或摘要
- 用户提到"论文"、"paper"、"研究"、"arXiv"
- 用户需要理解论文中的图表

## 工作流程

### 1. 论文录入

1. 用户上传PDF → 保存到论文存储
2. **用户必须主动点击"解析"按钮** — 不自动触发OCR，避免阻塞等待
3. 状态变化：待解析 → 解析中 → 已解析

### 2. 阅读论文

OCR完成后查看论文：
- **双栏显示**：原文（左）+ 翻译（右）
- **逐页对应**：第N页原文 ↔ 第N页翻译
- **可滚动分区**：每页独立滚动卡片

### 3. AI分析

点击"AI分析"获取：
- **逐段分析**：LLM分析每个论文段落（摘要/引言/方法/实验/结论）
- **核心发现**：提取核心贡献和方法
- **图表解读**：AI描述每张图表的内容

### 4. arXiv搜索

直接从arXiv搜索论文：
- 按标题/关键词
- 按作者名
- 返回标题、作者、摘要、PDF链接

## 使用的工具

- OCR：Unlimited-OCR模型（./OCR/）
- 翻译：基于DeepSeek的LLM翻译
- 搜索：ArxivClient调用arXiv API
- 存储：Paper/PaperPage/PaperFigure数据库模型
